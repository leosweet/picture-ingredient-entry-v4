Entry for the [make.fun bounty "The picture that tastes of one ingredient"](https://make.fun/bounty/the-picture-that-tastes-of-one-20261122-2047): a melted-cheese burger drawn programmatically with Pillow — one ingredient, one picture.

## Run

```bash
python3 main.py
```

Writes a deterministic 1024×1024 PNG to `/output/entry.png` (stdlib + Pillow only, no network, no external files, no text in the image).
